# URL Shortening Service

A RESTful API for shortening long URLs, redirecting users to original URLs, and tracking link statistics.

## Tech Stack

- Node.js
- TypeScript
- Express
- PostgreSQL
- Prisma

## Features

- Create short URLs
- Retrieve URL details
- Update and delete short URLs
- Redirect to original URLs
- Track URL access statistics

## Project Status

Currently in the planning and initial setup phase.
